# Discord Bot (Python)

A custom Discord bot built with Python using `discord.py`, designed to provide server utilities, moderation tools, and easily extendable features.

---

## Features

* Moderation commands (kick, ban, etc.)
* Server information commands
* Basic utility commands (customizable)
* Modular and easy-to-expand structure
* Lightweight and fast

---

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

---

## Configuration

Modify the `.env` file and add your bot token:

```env
TOKEN=your_discord_bot_token
```
then modify the last line 

⚠️ Never share your token publicly. Anyone with access to it can control your bot.

---

## Run the bot

### Windows

```bash
python main.py
```

### Linux

```bash
python3 main.py
```
